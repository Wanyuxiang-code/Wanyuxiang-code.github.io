# Yuxiang Wan's Personal Homepage

A warm and cozy academic personal homepage.

**Live Site:** [wanyuxiang-code.github.io](https://wanyuxiang-code.github.io)

## Quick Start

```bash
# Clone and run locally
git clone https://github.com/Wanyuxiang-code/Wanyuxiang-code.github.io.git
cd Wanyuxiang-code.github.io
python3 -m http.server 8080
# Open http://localhost:8080
```

## Customization

| Item | File | Location |
|------|------|----------|
| Avatar | `index.html` | Line 74 |
| Hero Background | `assets/css/main.css` | `.hero-background` |
| Colors | `assets/css/main.css` | `:root` CSS variables |
| Content | `index.html` | Each section |
